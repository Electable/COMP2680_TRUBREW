TRUBREW
  TruBrew is a modern, user-friendly website for a new café opening on the TRU campus that emphasizes local identity, affordability, and product variety. Through the website, TRU students can browse information about menu items, operating hours, and special deals, allowing them to place pickup orders instead of waiting in long lines.

o Instructions to run the website locally
- Download the ZIP folder and extract it to a place of your choosing. Then, run the "index.html" file to start the website.

o Known limitations and future enhancements
Limitations
- The website does not have database integration, meaning the website can’t dynamically update its product list and needs to be manually altered if a product is added or removed from the menu. However, this is a top-priority feature in a future update of the website. 

-The payment gateway features are not directly implemented. A user can input their card information, but nothing is actually registered, as this is a hypothetical company and location.

Future Prospects
-Dynamically updating the website to account for added or removed menu items. Adding all menu items to a database, and having the website create product boxes for each menu item in the database (also item-type dependant: hot drink, cold drink, etc)

-Further improve the SEO of the website. Including more focus on meta keywords, canonical tags, and structured data to improve the websites ranking on browsers.

- Create a dedicated page for TRU event postings. Where users can create, search for, and view posts for scheduled TRU events. This would make the TruBrew website a “common area” where students could see all TRU has to offer.
